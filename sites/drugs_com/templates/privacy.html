Local Data Handling

Runtime database

Registered account fields, password hashes, reviews, medication-list fixtures, notes, settings, and authenticated newsletter preferences are stored in the local SQLite runtime database. A site reset replaces that database with the deterministic seed.

Browser session

A signed browser cookie maintains login state. Signed cookies prevent undetected modification but are not encrypted. Authenticated review-vote choices are bounded and stored in the local account preference record. Anonymous newsletter and contact workflows retain only truncated SHA-256 receipt values and selected fixture categories; they do not retain a raw anonymous email, message, or medication-browsing history in the cookie.

Network behavior

The application performs no runtime analytics request, advertising request, email delivery, newsletter delivery, contact delivery, or other background request to an external service. User-activated links labeled as external can leave the local environment.

Operational logs

The surrounding WebHarbor process may write ordinary local HTTP access and error logs. Log retention and host access are controlled by the operator of the benchmark environment.

Local controls

Account fields and public-review visibility can be changed in account settings. Account deletion and external data requests are not implemented. Use only synthetic evaluation data in this environment.
