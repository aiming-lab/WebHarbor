What is the PBE?

The Public Beta Environment (PBE) is a limited-attendance environment where players can preview and test experimental changes before they reach the live servers. Feedback from PBE participants directly shapes upcoming patches.

How do I join?

PBE access requires an account in good standing that has reached level 9 or higher. Sign-ups open periodically when new content needs testing.

Report bugs

Found something broken on the PBE? File a report through the bug report tool so the team can reproduce and fix it.

Give feedback

Balancing feedback, skin feedback, and feature impressions all go into the same feedback tool the developers read.
