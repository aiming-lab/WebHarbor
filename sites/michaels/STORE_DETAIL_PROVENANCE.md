# Store detail workflow

Reference: https://locations.michaels.com/nc/cary/2122 (retrieved 2026-09-24).
The official city directory links to a store page containing opening hours and services.
The mirror follows that structure: directory cards retain addresses, phones and service summaries,
and link to per-store hours. All values come from the existing source_data.json store snapshot
via the seed database; no new commercial values are invented or fetched at runtime.
