# MEGA mirror notice

This is an offline benchmark mirror, not the live MEGA service. Branding and
imagery originate in the contributor's MEGA asset archive. Local users, files,
plans, support records, download metadata and payments are benchmark fixtures;
checkout does not process real payments and upload forms create metadata records.
Download checksum labels are fixture values, not cryptographic attestations of
real installers. Runtime content is read from the bundled SQLite seed.

The original archive is preserved byte-for-byte. `migrate_seed.py` makes tracked
schema/catalog corrections to the extracted seed during the image build.
